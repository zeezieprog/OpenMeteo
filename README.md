# Bandung Rain Tracker

Dashboard cuaca Kota Bandung untuk delapan titik pantau. Data kondisi terkini dan prakiraan berasal dari Open-Meteo. Halaman memeriksa sumber setiap menit selama aktif. Estimasi model terkini menggunakan interval 15 menit.

Jalankan `python -m http.server` dari folder ini lalu buka `http://localhost:8000`.
